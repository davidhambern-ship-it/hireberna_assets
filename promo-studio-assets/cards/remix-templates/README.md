# Ready-to-Remix Templates — Complete feature-card asset kit

[Manifest](../../manifest.json) · [Interactive preview](./preview.html)

An editable blank promo becomes a vivid personalized layout with real art, typography, CTA and palette controls.

## Assets
- `base.svg` — idle scene workstation
- `template-blank.svg` — independent animated or contextual SVG layer
- `template-ready.svg` — independent animated or contextual SVG layer
- `user-image.svg` — independent animated or contextual SVG layer
- `headline.svg` — independent animated or contextual SVG layer
- `cta.svg` — independent animated or contextual SVG layer
- `palette.svg` — independent animated or contextual SVG layer
- `cursor.svg` — independent animated or contextual SVG layer
- `sparkles.svg` — independent animated or contextual SVG layer
- `motion.css` — hover/focus/tap transitions, respects reduced motion.
- `preview.html` — playable QA preview, no external dependencies.
- `README.md` — source notes.

## Rendering constraints
600×360 viewBox for every SVG, absolutely layered in a 5:3 frame. All artwork fits without cropping (`object-fit:contain`). 1.55s staggered direction changes. All graphics original to Promo Studio. No claims of actual AI/publishing functionality in the UI sample.
