# APD Creative Director — Complete feature-card asset kit

[Manifest](../../manifest.json) · [Interactive preview](./preview.html)

The director gathers an idea, an image, copy and timed scenes into one assembled promo composition.

## Assets
- `base.svg` — idle scene workstation
- `director-core.svg` — independent animated or contextual SVG layer
- `idea.svg` — independent animated or contextual SVG layer
- `image.svg` — independent animated or contextual SVG layer
- `copy.svg` — independent animated or contextual SVG layer
- `timeline.svg` — independent animated or contextual SVG layer
- `promo-frame.svg` — independent animated or contextual SVG layer
- `beam.svg` — independent animated or contextual SVG layer
- `sparkles.svg` — independent animated or contextual SVG layer
- `motion.css` — hover/focus/tap transitions, respects reduced motion.
- `preview.html` — playable QA preview, no external dependencies.
- `README.md` — source notes.

## Rendering constraints
600×360 viewBox for every SVG, absolutely layered in a 5:3 frame. All artwork fits without cropping (`object-fit:contain`). 1.55s staggered direction changes. All graphics original to Promo Studio. No claims of actual AI/publishing functionality in the UI sample.
